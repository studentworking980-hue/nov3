After powering the board connect it through serial connection 
1. On the VEK280 board — PuTTY/serial
ip link set end0 up
ip addr flush dev end0
ip addr add 192.168.1.85/24 dev end0

Check:
ip addr show end0
ip route

You should see:
inet 192.168.1.85/24

2. On the host PC
sudo ip link set eno2 up
sudo ip addr flush dev eno2
sudo ip addr add 192.168.1.52/24 dev eno2

Then:
ip addr show eno2

You should see:
inet 192.168.1.52/24

3. Check the route
Run:
ip route

You should have:
192.168.1.0/24 dev eno2 proto kernel scope link src 192.168.1.52

If it isn't there:
sudo ip route add 192.168.1.0/24 dev eno2 src 192.168.1.52
